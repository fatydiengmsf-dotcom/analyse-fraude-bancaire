#  Analyse des transactions bancaires et détection des fraudes

## Présentation

Ce projet porte sur l'analyse de transactions bancaires et la détection des transactions potentiellement frauduleuses à l'aide de techniques de Machine Learning.

## Objectifs

- Explorer et comprendre les données de transactions bancaires
- Identifier les caractéristiques associées aux transactions frauduleuses
- Préparer et nettoyer les données
- Construire des modèles de Machine Learning
- Évaluer les performances des modèles
- Identifier les transactions susceptibles d'être frauduleuses

## 📊 Dataset

Le projet utilise le dataset **Credit Card Fraud Detection**, contenant des transactions par carte bancaire dont certaines sont identifiées comme frauduleuses.

## 🔎 Analyse exploratoire

L'analyse porte notamment sur :

- la distribution des transactions ;
- la répartition entre transactions légitimes et frauduleuses ;
- les variables disponibles ;
- les éventuels déséquilibres entre les classes.

## 🤖 Machine Learning

Les données sont préparées afin d'entraîner et d'évaluer les modèles de Machine Learning utilisés pour la détection des fraudes.
